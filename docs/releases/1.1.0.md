# S5LBox 1.1.0

Browse Legacy Store, manage guest files without leaving S5LBox, and enjoy a more reliable iPhone OS experience.

## What's new

- **Legacy Store:** native browsing, search, artwork, and individual app downloads inside IPA Library. Results are filtered for the guest, with a choice of compatible archived versions. Downloaded IPAs are validated before installation; filtering does not guarantee that every app will run.
- **Guest Files:** browse Media, preview and export files, import files, create folders, rename items, and delete empty folders or files over virtual USB. Jailbroken guests can also expose the full filesystem.
- **AppSync setup:** new guest jailbreaks install AppSync for OS 3.1 by default, with an independent opt-out in Advanced settings.
- **Home-only interface:** a minimal alternative to the Modern and Legacy layouts, with hidden controls available through the screen margin and VoiceOver.
- **Firmware import option:** Advanced > Firmware can skip stock checksums before an IPSW is imported. Archive integrity, device validation, and kernel safety checks still apply; custom firmware compatibility is not guaranteed.

## Fixes and improvements

- Guest date and timezone follow the host iPhone, including after saved-session resume, background pauses, and timezone changes.
- Silent mode is remembered separately for each machine across restarts and resume.
- Audio buffering better handles uneven delivery and recovery without changing guest clocks or pitch. Microphone capture starts only when the guest requests input.
- Home wakes a guest whose display is asleep, even when the rest of the guest is still running.
- IPA and Packages controls become available when boot or restore finishes, without reopening Machine Settings.
- Firmware preparation runs off the UI thread. Force Power Off remains available during startup, saving, and restart, canceling unfinished preparation work.
- First-boot jailbreak setup initializes package dependency records, and Packages waits for setup to finish before offering operations.
- Safe file links inside legacy IPAs are preserved; unsafe paths, cycles, missing targets, and directory links are rejected.
- Cold-boot file connections allow stock AFC pairing to complete. Transfers have clearer state, preserve guest errors, and clean up temporary previews.
- A verified HTTPS CDN fallback handles affected Saurik archive download failures without disabling certificate or archive verification.
